## 1. قائمة الفحص التشغيلي الميداني

- [x] **تنوع الأجهزة (Platform Coverage)**: فحص واختبار جهاز Android physical device + iPhone physical device.
- [x] **اعتماد الأجهزة الموثوقة (Trusted Device Workflow)**: فحص دورة حياة طلب اعتماد جهاز جديد (Pending -> Admin Approval -> Approved / Rejection / Revocation).
- [x] **تسجيل الحضور اليومي (Daily Check-In)**: تسجيل الحضور بنجاح داخل النطاق الجغرافي المعتمد للفرع.
- [x] **تسجيل الانصراف اليومي (Daily Check-Out)**: تسجيل الانصراف وإغلاق جلسة الحضور بنجاح مع حساب إجمالي الدقائق.
- [x] **إدارة الاستراحات (Breaks Lifecycle)**: فحص بدء واستكمال الاستراحات مع تطبيق قاعدة منع تكرار الاستراحات النشطة.
- [x] **دقة وتأكيد النطاق (Geofence Engine)**: تأكيد حالة `INSIDE_CONFIRMED` داخل الفرع، وحظر الحضور مع `OUTSIDE_CONFIRMED` خارج الفرع دون توسيع شعاع النطاق عند ضعف GPS.
- [x] **منطقة عدم التأكد (Uncertainty Zone Flow)**: اختبار تعامل المنظومة عند الـ GPS الضعيف (إعادة المحاولة / طلب تأكيد الموقع من الإدارة Manager Verification).
- [x] **موافقة وتدقيق المشرف (Manager Location Verification)**: معالجة طلب تأكيد الموقع من لوحة الإدارة وتسجيل وسم المصدر الصريح `ADMIN_VERIFIED`.
- [x] **الإشعارات اللحظية (Real-time SSE & Fallback)**: وصول إشعارات الاعتماد والنطاق فوراً في الواجهة، واستئناف الاتصال تلقائياً `visibilitychange` فور عودة التطبيق من الخلفية.
- [x] **التعافي عند الانقطاع (Network Interruption & Recovery)**: عرض تنبيه الشبكة الواضح عند وضع الطيران وإعادة الاتصال التلقائي بدون تكرار التنبيهات.
- [x] **حسابات الورديات (Shift Calculations)**: احتساب التأخير والخروج المبكر بشكل دقيق وفق باني الورديات 2026.
- [x] **مطابقة البيانات اليومية (Daily Data Reconciliation)**: مطابقة سجلات قاعدة البيانات يومياً والتأكد من عدم وجود جلسات مكررة أو سجلات يتيمة.
- [x] **مؤشر صحة المنظومة (System Health Telemetry)**: متابعة شاشة `/admin/system-health` والتأكد من النتيجة `100/100 HEALTHY`.
- [x] **فحص سلامة النسخ الاحتياطي (Backup Verification)**: التأكد من سريان حالة `BACKUP & RESTORE VERIFIED` دون أي مساس ببيانات الإنتاج.
